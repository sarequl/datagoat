# DataGoat

Open-source, revenue-first web analytics that runs in your own Cloudflare account: one Worker, one D1 database, one script tag. MIT licensed.

DataGoat shows which channels, pages and campaigns bring paying customers, not just visitors, by joining a first-party visitor id to your Stripe, Polar, Lemon Squeezy, Paddle, Dodo, Creem, Shopify or WooCommerce payments. It is drop-in compatible with DataFast's tracking script and payment metadata, so switching is a snippet swap.

Status: under construction.
