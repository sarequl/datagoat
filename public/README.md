# public/ (build output)

Everything in this folder is generated by `npm run build` and served by Workers Static Assets:

- `index.html`, `assets/*`: the dashboard SPA (from `dashboard/`, built by Vite)
- `js/script.js`, `js/script.cookieless.js`, `js/script.hash.js`: the tracker (from `tracker/`, built by esbuild)
- `_headers`, `robots.txt`: copied from `static/`

Do not edit files here; they are git-ignored and recreated on every build.
